# KAP - KAM (KAT Advanced Medical) Advanced Pharma

[KAP](https://steamcommunity.com/sharedfiles/filedetails/?id=3479793625) is an extension for [KAT - Advanced Medical](https://steamcommunity.com/sharedfiles/filedetails/?id=2020940806). This mod aims to extend the default medication types in KAT and ACE medical. The mod is in a very early stage of development and doesn’t have a lot of content yet. I aim for monthly updates after the initial development phase.

**Current added medication**
- Cannabis Gummies
- Cyanide (disabled by default—enable in addon options)
- Zagustin
- Meth
- Paracetamol
- Vicodin
